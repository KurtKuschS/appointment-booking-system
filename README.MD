# Appointment Booking System

Sistema web desarrollado como proyecto personal para la gestión y reserva de horas en un salón de extensiones de pestañas.

## Objetivo
Permitir a clientas reservar horas de atención y a la administradora del salón gestionar servicios, horarios y reservas mediante una interfaz simple y funcional.

## Tecnologías
- Python
- Django
- PostgreSQL
- HTML / CSS

## Funcionalidades planificadas
- Registro e inicio de sesión de usuarios
- Roles: clienta y administradora
- Gestión de servicios
- Definición de horarios disponibles
- Reserva y cancelación de horas
- Dashboard administrativo con reportes básicos
